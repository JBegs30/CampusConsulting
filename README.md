# Freshman Campus Mobility Site

This folder is ready for GitHub Pages.

## Before publishing
Open `index.html` and replace:
- `YOUR_SIGNUP_FORM_LINK`
- `YOUR_UPLOAD_LINK`

## Publish on GitHub Pages
1. Create a free GitHub account if needed.
2. Create a new public repository, for example `freshman-campus-mobility`.
3. Upload all files in this folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then save.
7. GitHub will display your public site URL after deployment.

No build tools are required.
